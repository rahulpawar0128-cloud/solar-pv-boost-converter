Design and Development of Boost Converter for SPV System

Project Overview

This project focuses on designing a DC–DC boost converter for a solar photovoltaic (SPV) system to increase the solar panel voltage from approximately 17–18 V to 24 V DC.

Objectives

- Increase the solar panel's DC output voltage.
- Study PWM generation using a 555 timer IC.
- Calculate the duty cycle and inductor value.
- Understand circuit design, component selection, and output voltage stability.

Technologies and Skills

- Power Electronics
- Solar Photovoltaic Systems
- DC–DC Boost Converters
- PWM Generation
- 555 Timer IC
- Circuit Design and Testing

Project Documentation

The project report contains the design calculations, circuit diagram, methodology, results, and conclusion.
